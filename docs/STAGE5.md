# Stage 5：同じ引き金、違う傷跡

メニュー→Stage 5で開始。8場面：条件→予想→初回→作用者交換→2×2比較→介入→再実験→振り返り。初回の結果を見ると条件・予想・理由・確信度を固定します。新しい条件は終幕の「新しい実験」から試せます。

## 説明用モデル

A/Bの確認経路と監査経路、作用α/βの強さはいずれも0–100。拡散＝強度×(1−確認経路/100)、監査で見えない部分＝強度×(1−監査経路/100)。実測較正なしの静的モデルで、時間発展・復旧・住民行動は含みません。確認・監査が指標を改善する関係そのものも仮定です。

初期条件はA:確認20/監査80、B:確認80/監査20、α=β=70。同じ強さの作用者交換で結果が変わらないことは式から導かれ、人物の影響が小さい証拠にはなりません。強さや地域条件を変更し、差が消える条件と現れる条件を確かめます。

各地域の介入予算は25。一経路に25を加算し上限100、費用25固定。何もしない費用は0。介入後は初回と同じ配置・強度を再使用し、作用者交換の影響と混ぜません。費用・効果量は架空で、政策の最適解や実現可能性は評価しません。

## 記録と再現

JSONはモデル版、場面、入力、予想、回答、介入を保存。読み戻しは型・範囲・版・100KB上限を検証し、出力は再計算。不正なファイルは現在の回答を置き換えません。回答の外部送信・自動保存は行いません。JSONの自由記述は保存する本人が管理してください。

## 学習の問い

どの結果が仮定から決まっていたか。何が観測されたらモデルを修正するか。介護相談窓口の集約なら、平均待ち時間のほかに何を調べるか。特定政策への賛否を採点しません。操作テストの通過は教育効果の証明ではありません。
