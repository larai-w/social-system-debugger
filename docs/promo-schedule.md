# X 投稿スケジュール — 社会デバッガー

素材は揃っている。あとは順番に出すだけ。**一度に出さない。2〜3日空ける。**

前提のルール（`veai-private/.../x-post-templates.md` が一次ソース）:
ハッシュタグは `#社会デバッガー` 1つ / URL は Pages の1本 /
実在の地名・人名・政局に触れない / 免責1行 / 動画には「※演出用に簡略化した
デモ映像です」/ 宣伝ではなく **結果そのもの**を運ぶ。

**動画は必ず MP4 を使う。** X は webm を受け付けない（`dist/social-reels/*.mp4`）。

---

## 全体の設計

初回だけ「何のプロジェクトか」を伝え、**2本目以降は実験結果だけを流す**。
宣伝の連投にしない、というルール6をスケジュールの形で担保する。

## 順番の理由

- **02 に会議の話を置く。** 4ページの中で最も具体で、前提知識がいらない
- **03 で直感に反する結果を出す。** 「効率的な街が最悪の日に負ける」は
  反応を取りやすく、かつ本題（余力の価値）に直結する
- **04 で倫理設計を見せる。** 実名を出さない設計そのものが差別化になる。
  早い段階で出すと、以降の投稿が安心して読まれる
- **05 でインストール導線。** 3本見て興味を持った人が対象。最初に出すと早い
- **08 は 01 の続き。** 問題提起（声の大きさ）→ 解決（結果との接続）の対
