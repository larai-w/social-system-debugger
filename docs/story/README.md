# ストーリー設計

ここは将来機能の物語設計と、既存シナリオでの検証状況をまとめる場所。
実装済みの週次JSON本体は `content/weekly/` が一次ソース。

## PAGE 5候補

正式な設計凍結ノートは [`page5-design-note.md`](page5-design-note.md)。候補は次の5系統。
完成ストーリーは [`page5-complete-story.md`](page5-complete-story.md)。これは実装前に体験の順序・台詞・分岐を固定する物語仕様であり、公開ゲートは解除しない。
画面構成と演出は [`page5-storyboard.html`](page5-storyboard.html) で8シーンを視覚確認できる。
上部ボタンまたは左右キーで移動する。`?scene=0`〜`?scene=7` を付けると任意のシーンを直接開ける。

1. **LOUD CRASH** — 大規模・高断層・高注目市場で、分断が機能麻痺へ拡大する。
2. **SILENT CAPTURE** — 小規模・高信頼の陰で、対抗ノード不足による私物化が長期間発見されない。
3. **SWAP THE LEADER** — リーダーを交換しても壊れる側が変わらず、人物より攻撃面が原因だと示す。
4. **半外部ノード注入** — 内部の信頼へ参加しつつ外部視点を持つノードが、監査カバレッジを戻す。
5. **同じショック、違うOS** — 同一ショックを2つの社会条件へ入れ、共有現実バッファの差を比較する。

## 着手ゲート

- SWAP THE LEADER先行版: 週次を4週以上運用し、ユーザー20〜30人の基礎値を得てから。
- PAGE 5フル版: PAGE 5系週次の反応データ、ユーザー50人前後、フェーズ2完了後。
- 条件を満たすまでは、本編コードや確定ストーリーを作らず、既存ページ上の週次で素材だけ検証する。
