# Claude Code 実装依頼: generateEtiquetteCard() のデザインを参考コードに合わせて移植

## 背景

添付する `share-card-generator.html` は、共有作法カード（1200×630）のデザイン検討用に
別途作った参考実装です。この中の `drawEtiquette()` 関数（および呼び出している
`rrect()` 等のヘルパー）が、作法カードとして意図しているデザインの完成形です。

現在アプリ側に実装済みの `generateEtiquetteCard()` は、文言だけは正しく
`sg_dont` / `sg_note` と完全一致していますが、レイアウト・配色・余白などの
見た目は文章指示から起こしたものなので、参考コードとズレがあります。
今回は **見た目だけを参考コードに合わせて移植** してください。

## やってほしいこと

1. 添付の `share-card-generator.html` を読み、その中の `drawEtiquette()` 関数
   （1200×630 canvas に「⇪ 共有のつかいかた — 送るときの3か条」を描画している部分）
   のデザインを確認する。この関数**以外**の部分（タブ切り替えUI、`drawOGP()`、
   PNGダウンロードボタンなど）はこのファイル固有のもので、今回の移植対象ではない。
   参照するのは `drawEtiquette()` と、それが呼ぶ `rrect()` のみでよい。

2. `generateEtiquetteCard()` を、`drawEtiquette()` と同等の見た目になるよう書き換える:
   - 背景 `#070b14` ＋ 48px間隔のシアン格子（薄）
   - ヘッダー: 「⇪ 共有のつかいかた — 送るときの3か条」（シアン太字・グロー付き）
   - サブタイトル: 「気まずい話題ほど、送り方がすべて。」（明るめの白系、太字）
   - 免責サブライン: 「※ これは推奨する共有方法の一例です。必ず守るべきルールではありません。」
   - 3つのルールカード（各行が背景ボックス＋左に番号バッジ＋タイトル＋説明文の横並び構成）:
     01（赤 `#ff2244`）/ 02（黄 `#ffcc00`）/ 03（緑 `#00ff88`）、
     各ボックスは薄い塗り＋同色の枠線、番号は大きく発光させる
   - フッター帯: 背景ボックス＋区切り線＋免責文＋アプリ名（v6.3表記）
   - 座標・サイズ比率は `drawEtiquette()` の値をベースにしつつ、
     アプリ側のcanvas生成関数の作法（既存の `generateResultCard()` の書き方）に
     合わせて自然な形に調整してよい

3. **文言は一切変更しない。** 現状の `generateEtiquetteCard()` が使っている
   `sg_dont[0]`（人名を添えない）/ `sg_dont[1]`（答えを言わない）/
   `sg_dont[3]`（好奇心だけ添える）と `sg_note` の文字列は、そのまま流用する
   （参考コードの中の文言はダミーなので、参考コード側の文字列で上書きしないこと）。

4. `getEtiquetteCardBlob()` のキャッシュ機構、`saveEtiquetteCard()` の保存ボタン挙動、
   `shareWithEtiquette()` との連携は、既存の実装をそのまま維持する
   （今回変更するのは `generateEtiquetteCard()` の描画内容のみ）。

## 確認してほしいこと

- 変更後、前回お願いした「プレビュー用HTML」（`generateEtiquetteCard()` を呼んで
  結果を画面に表示するだけの単体HTML）を作り、実際の描画結果を見せてほしい
- 日本語テキストの折り返し・文字がボックスからはみ出していないか目視確認する
- 既存の `sg_dont` / `sg_note` の文字列との一致を、今回の書き換え後も再度チェックする
- 変更は `generateEtiquetteCard()` 関数のみに閉じ、他の共有まわりの関数
  （`shareWithEtiquette` / `canShareMultipleFiles` / `shareResultCard` 等）には触れない

まずは添付ファイルの `drawEtiquette()` を読んで、移植方針を短く提示してから着手してください。
