# プロモーション・キャンペーン

完成済み30秒リールは「1企画＝1フォルダ」。各フォルダに映像原稿 `reel.html` と投稿文 `post.md` を置く。

| フォルダ | テーマ | 用途 |
|---|---|---|
| `page4-meeting/` | 6人の会議と1000の声 | 固定ポスト第一候補 |
| `page1-safe/` | 誰の話もしていない | 静かで知的な導入 |
| `page2-resonance/` | 救命ヘリと責任回避 | 刺激的な構造批判 |
| `page3-distance/` | 接続と現実の距離 | 認知回復 |
| `page2-shock-lab/` | 平時の勝者と最悪の日 | 比較実験 |
| `page2-timelapse/` | 20年の静かな劣化 | 長期視点 |
| `sector-h-characters/` | 同じ3人、違う会話設計 | 人物非難を避ける説明 |
| `sector-h-flow/` | 社会を詰まらせる流れ | システム図解 |
| `page4-outcome/` | 声と結果の接続 | PAGE 4短縮版 |
| `page2-classic-shock/` | 同じ災害、違う結末 | 初期30秒版／予備 |

一括録画は `make social-reels`。投稿直前の番号付きパッケージは `make x-launch-kit`。
旧長尺リールと生成器は `promo/archive/` に保存している。
